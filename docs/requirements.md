# requirements

## project scope

This project covers the basic functional flows of the SauceDemo web application using UI automation with Playwright and pytest.

## functional requirements

### req-01: valid login
The system should allow a user with valid credentials to access the inventory page.

### req-02: invalid login
The system should prevent login when invalid credentials are entered and display an error message.

### req-03: inventory page
After a successful login, the system should display the inventory page with available products.

### req-04: add product to cart
The system should allow a logged-in user to add a product to the shopping cart.

### req-05: cart navigation
The system should allow a logged-in user to navigate to the shopping cart.

### req-06: checkout flow
The system should allow a logged-in user with a product in the cart to start checkout and continue to the checkout overview page.

## test basis

These requirements are used as the test basis for the automated test cases in this project.
